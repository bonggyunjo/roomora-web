# Roomora Web (`roomora-web`)

> **Roomora (루모라)** — 조건 기반 인테리어 레시피 · 주간 콘테스트 · AI RAG 통합 검색 플랫폼의 프론트엔드 웹입니다.  
> 기존 Vue 2.7(EOL) 레거시에서 **Nuxt 3 (SSR) + Pinia + Tailwind CSS** 기반으로 전면 재구축했습니다.

## 기술 스택
- **Framework**: Nuxt 3 (Vue 3 SSR, File-based Routing)
- **State & Styling**: Pinia, Tailwind CSS
- **SEO & Sharing**: Nuxt `useSeoMeta` 기반 레시피/콘테스트 OG 메타태그 지원
